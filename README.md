# Galaxy AI Enabler для Samsung One UI 9

Модуль для разблокировки и активации функций **Galaxy AI** на устройствах Samsung под управлением **One UI 9**.

---

## ⚠️ Важные требования и совместимость

Перед установкой внимательно ознакомьтесь с ограничениями. Модуль будет работать **только** при соблюдении всех условий:

* **Устройство:** Исключительно смартфоны и планшеты **Samsung**.
* **Прошивка:** Только **One UI 9** (на других версиях One UI работа не поддерживается и может привести к бутлупу).
* **Права доступа:** Обязательно наличие **Root-прав**.
* **Менеджер модулей:** Поддерживаются только **Magisk** или **KernelSU**.

---

## ✨ Возможности

* Активация встроенных функций Galaxy AI на поддерживаемых прошивках One UI 9.
* Системная интеграция через бесшовную подмену необходимых свойств и конфигураций (без модификации `/system` напрямую).

---

## 📥 Установка

1. Скачайте актуальный `.zip` архив модуля из раздела [Releases](../../releases).
2. Откройте приложение **Magisk** или **KernelSU** на вашем устройстве Samsung.
3. Перейдите во вкладку **Модули** -> **Установить из хранилища**.
4. Выберите скачанный архив с модулем.
5. Дождитесь завершения установки и нажмите **Перезагрузить**.

---

## 🛠 Удаление (в случае проблем)

Если после установки возникли ошибки или устройство не загружается:
1. Загрузитесь в безопасный режим (Safe Mode) — Magisk и KernelSU автоматически отключат все модули.
2. Либо удалите папку модуля через KernelSU
3. / OrangeFox по пути `/data/adb/modules/`.
